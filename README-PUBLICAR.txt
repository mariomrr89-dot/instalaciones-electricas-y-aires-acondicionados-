SOLUCIONES ELÉCTRICAS PV - CÓMO PUBLICAR

OPCIÓN MÁS FÁCIL: NETLIFY DROP
1. Descomprime el archivo ZIP.
2. Entra a https://app.netlify.com/drop
3. Arrastra la carpeta completa "soluciones-electricas-pv".
4. Netlify publicará el sitio y te dará una dirección temporal.
5. En Site configuration > Domain management puedes cambiar el nombre o conectar un dominio propio.

EDITAR LA PÁGINA
- Abre index.html con cualquier editor de texto.
- Para cambiar el teléfono busca: 523224450320 y 322-445-03-20.
- Para cambiar textos, busca el texto en español dentro de index.html.
- Para cambiar la foto sustituye promocion-espanol.png conservando exactamente el mismo nombre.
- Para cambiar el logo sustituye logo.svg.

OTRAS OPCIONES
- GitHub Pages: sube todos los archivos a un repositorio y activa Pages.
- Vercel: importa el repositorio o arrastra la carpeta mediante su interfaz.
